04b — WHAT'S UNDER THE HOOD

A synthesis pipeline, not a diagram tool

Frontend
Multi-file upload with folder support. Relative $readmemh paths are preserved so firmware hex files resolve correctly. Top module auto-detected or overridden.
Synthesis
Real Yosys: read_verilog -sv → hierarchy → proc → opt → clean, sandboxed per request in a temp directory that's deleted after the response.
Layout
Eclipse Layout Kernel, layered left-to-right, orthogonal edge routing. Every gate is a real SVG element, not a raster image — export stays vector at any zoom.
Timing
On-demand techmap to real gates, then a topological longest-path walk gives gate depth. Converted to nanoseconds at 180/90/45/7nm process estimates, with the top-15 critical paths broken down cell by cell.
Source mapping
Every cell carries Yosys's src attribute back to your original file and line number. Hover a gate, the matching source line highlights — and back.
Views
Simple (block diagram), Hybrid (auto-switches on zoom), and Detailed (every primitive gate) — from one compile, no re-run needed to switch.
